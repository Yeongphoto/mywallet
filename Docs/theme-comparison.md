# 기본 / 테마1 비교

테마1의 입체 기준은 좌상단 광원으로 통일한다. 돌출 버튼·카드는 좌상단 밝은 모서리와 우하단 1px 그림자, 눌린 버튼은 반대의 안쪽 명암을 사용한다. 메뉴·선택 탭의 강조선은 아래쪽 2px이며 상태 변경으로 크기나 위치가 움직이지 않는다. 카드 제목 구분선과 빈 목록에 워드마크의 세 사각 점(두 개의 잉크색·마지막 민트색)을 작게 배치한다. 연간 그래프 제목에는 장식을 추가하지 않아 한 줄 탭의 공간을 유지한다.

설정의 **디자인**에서 `기본`과 `테마1`을 즉시 전환한다. 기본은 기존 파스텔·둥근 모서리 스타일이며, 테마1은 같은 팔레트·픽셀 워드마크를 유지하고 직각 모서리·얇은 테두리·선택 표시선을 사용하는 비교안이다. 라이트·다크·시스템 모드 선택은 별개로 유지한다.

기기 외형 설정에 `theme1` 값을 추가했다. 이전 `doodle`·`mememo` 값은 호환성을 위해 읽지만 외형은 기본으로 표시하며 선택 목록에는 노출하지 않는다. 공통 패밀리 배치는 `data-style-theme="default"`로 유지하고 새 비교 스타일만 `data-ui-theme="theme1"`로 구분한다. `src/theme1.css`가 비교안의 외형을 담당한다.

기존 기기별 외형 저장 경로를 사용하며 로그인·공유 관리·로컬·클라우드 장부에서 같은 선택을 반영한다. 초기 HTML도 선택 값을 읽어 첫 렌더링부터 적용한다. 테마 변경으로 금융 API 저장을 호출하거나 기록의 `updatedAt`을 갱신하지 않는다.

검증: 라이트·다크 각각 411/800/1024 폭에서 직접 버튼 전환과 모서리·가로 넘침을 확인하고, 재실행과 로그인 화면 진입 후 선택 유지, 로컬 기록·자산·예산·데이터 시각 보존 및 금융 네트워크 쓰기 0회를 검사한다. APK는 새로 만들지 않는다.
