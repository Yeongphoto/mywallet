# 장부 선택과 로그아웃

2026-10-25 사용자 확정: 로그인한 개인·공유 장부의 선택 목록에서 기기(로컬) 장부를 숨긴다. 별도 기기 전환 버튼은 추가하지 않고 기존 ‘연결 끊기’도 제거한다. 계정의 로그아웃을 정상 완료하면 `/guest#settings`에서 기존 기기 장부를 연다. 기기 장부에서는 선택 항목을 ‘기기 장부’로 표시하고 기존 ‘연결’ 버튼을 유지한다.

서버 로그아웃이 실패하면 기기 장부로 이동하지 않고 기존 재시도 화면을 유지한다. 권한 상실·세션 만료의 재인증 경로는 `/signin`을 유지한다. Google 계정의 개인·공유 장부와 참여 권한, 장부 UUID 및 기기 장부 저장 키는 변경하지 않는다. 로그아웃을 데이터 이전·합치기·초기화로 취급하지 않는다.

검증: production 빌드 및 `node scripts/check-ledger-settings.mjs`. 격리 브라우저와 API 모의 응답으로 320/768px × 라이트/다크 × 개인/공유 8개 조합에서 클라우드 목록의 기기 항목 비노출, 중복 전환 버튼 제거, 정상 로그아웃 후 기존 기기 자산·거래·정기기록·예산 보존, 실패 후 재시도를 확인했다. 실DB 접근은 없고 금융 쓰기 호출은 0건이다. 이번 단계는 로컬 커밋이며 앱 버전·Play 배포는 별도 요청 시 진행한다.
