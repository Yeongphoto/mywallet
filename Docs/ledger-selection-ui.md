# 장부 선택과 로그아웃

추가 정리: 장부 선택 드롭박스는 장부 목록만 표시한다. 기존 공유장부 관리/만들기 항목은 제거하고 설정 → 데이터의 장부 보관 및 복구 영역에 ‘관리’로 통합한다. 공유장부 호스트에게는 삭제 예약 버튼 왼쪽에 표시하고, 게스트에게도 관리 진입점은 제공하되 이름 수정·멤버 권한 등의 서버 소유권 규칙은 유지한다. 공유 관리 화면의 이름 변경 제출 문구는 ‘변경’이다. 기기 장부에는 원격 공유 관리 버튼을 추가하지 않는다.

2026-10-25 사용자 확정: 로그인한 개인·공유 장부의 선택 목록에서 기기(로컬) 장부를 숨긴다. 별도 기기 전환 버튼은 추가하지 않고 기존 ‘연결 끊기’도 제거한다. 계정의 로그아웃을 정상 완료하면 `/guest#settings`에서 기존 기기 장부를 연다. 기기 장부에서는 선택 항목을 ‘기기 장부’로 표시하고 기존 ‘연결’ 버튼을 유지한다.

서버 로그아웃이 실패하면 기기 장부로 이동하지 않고 기존 재시도 화면을 유지한다. 권한 상실·세션 만료의 재인증 경로는 `/signin`을 유지한다. Google 계정의 개인·공유 장부와 참여 권한, 장부 UUID 및 기기 장부 저장 키는 변경하지 않는다. 로그아웃을 데이터 이전·합치기·초기화로 취급하지 않는다.

검증: production 빌드 및 `node scripts/check-ledger-settings.mjs`. 격리 브라우저와 API 모의 응답으로 320/768px × 라이트/다크 × 개인/공유 8개 조합에서 클라우드 목록의 기기 항목 비노출, 중복 전환 버튼 제거, 정상 로그아웃 후 기존 기기 자산·거래·정기기록·예산 보존, 실패 후 재시도를 확인했다. 실DB 접근은 없고 금융 쓰기 호출은 0건이다. 이번 단계는 로컬 커밋이며 앱 버전·Play 배포는 별도 요청 시 진행한다.

사용자의 별도 배포 요청에 따라 `b6f7cca`(가이드 토글 `0c5c403` 포함)로 production 빌드와 서명 검증 후 `6 (0.1.6)` AAB를 내부 테스트에 출시했다. SHA-256은 `c225e3835a97597667653e7a55f726645852d3655767ea298f3f7f066ecdaaf8`이다. 2026-10-25 11:20 KST Console의 최신 출시 버전 `6 (0.1.6)` / ‘내부 테스터에게 제공됨’을 확인했다. 검토 경고는 기존 가독화 파일 미첨부 1건이며 차단 오류는 없었다. 기존 API/DB/서명/Google 로그인 설정을 유지했고 서버 재배포·금융 데이터 변경·공개 출시·Git 푸시는 수행하지 않았다. 실제 설치 기기 업데이트 후 검수는 아직 하지 않았다.

브라우저 작업 중 Orca 관찰/조작 후 최대화가 해제되는 것을 Windows `IsZoomed`로 확인했다. 마지막 출시 확인과 결과 읽기는 직접 UI Automation으로 수행해 창 크기를 유지했고, 작업 종료 시 `IsZoomed=true`를 확인했다. 이 환경에서는 최대화/복구 버튼의 접근성 이름만으로 실제 최대화 상태를 단정하지 않는다.
