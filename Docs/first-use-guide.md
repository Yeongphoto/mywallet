# 첫 사용 가이드와 연간 자산 축

2026-10-24 · android_dev.

연간 그래프의 자산/자산(부채포함) 축에서 1억원 이상은 `1.30억`, `1.31억`처럼 소수점 두 자리로 표시한다. 음수도 같은 규칙을 사용하며 지출입 그래프의 기존 축 표기는 유지한다. 금액 계산·자산 평가·장부 집계·그래프 범위는 변경하지 않는다.

첫 가이드는 자산 탭 → 자산 등록 + → 등록창을 닫은 후 장부 탭 → 거래 등록 + → 계획 탭 → 비교 안내 순서의 3단계다. 실제 메뉴 버튼을 하이라이트하고 주변에는 3px 블러와 22% 검정 배경을 표시한다. 강조 영역은 이전 프레임보다 가로·세로 각각 10% 키우며 그 안은 블러를 잘라내 버튼을 선명하게 유지한다. 블러 구멍과 테두리는 같은 좌표·크기·반경(최대 20px)의 둥근 경계를 사용한다. 사각 polygon 구멍과 라운드 테두리를 혼용하지 않는다. 안내는 화면 중앙보다 조금 위에 최대 380px 너비, 20px 본문으로 표시하며 짧은 가로 화면에서는 대상 버튼과 겹치지 않도록 이동한다. 하이라이트는 실제 버튼의 조작을 막지 않는다. 등록 모달·수정/설정/확인 모달·동기화 중에는 입력을 가리지 않는다. 별도의 등록/저장 흐름을 만들지 않고 기존 버튼을 사용한다.

- 기존 사용자도 완료 표식이 없으면 한 번 표시한다.
- 기존 자산이 있으면 `이미 자산이 있어요 →`로 거래 안내를 진행할 수 있다.
- 자산 등록창을 한 번 열고 닫으면 저장·취소 여부와 관계없이 장부 안내로 넘어간다. 자산 생성이나 자산 수 증가를 요구하지 않으며, 취소만으로 자산을 생성하거나 저장하지 않는다.
- 거래 등록 창을 열면 계획 안내를 준비하고, 입력창을 닫은 뒤 계획 탭을 안내한다. 거래 저장을 강제하지 않는다. 계획 탭에서 예산 입력 후 결산의 실제 지출과 비교할 수 있음을 안내하고 ‘가이드 마치기’로 완료한다.
- 자산 안내에는 ‘설정 → 자산관리’에서 자산 카테고리를 관리할 수 있음을, 장부 안내에는 ‘설정 → 카테고리’에서 지출·수입 카테고리를 관리할 수 있음을 덧붙인다.
- 닫기/가이드 끄기/안내 중 Escape도 완료로 기록한다. 등록 모달의 Escape를 가이드가 가로채지 않는다.
- 완료 표식은 기기 브라우저/WebView의 `memoney:usage-guide:v1:completed`다. 계정·장부 금융 데이터나 DB 동기화에 넣지 않는다. 같은 설치의 일반 업데이트/재실행에서는 유지되며 앱 데이터 삭제·재설치·다른 기기에서는 새 안내가 나올 수 있다.
- 기기 저장소를 쓸 수 없을 때는 현재 페이지 메모리에서 닫기 상태를 유지한다. 영구 저장이 불가능한 환경까지 재실행 비표시를 보장하지 않는다.

2026-10-25 재실행 설정: 설정 → 환경의 `사용 가이드`에서 켜기/끄기를 제공한다. 켜기는 완료 표식을 해제하고 차트 화면에서 자산 탭 안내부터 새 회차를 시작한다. 이미 진행 중이어도 켜기를 누르면 처음부터 시작한다. 끝까지 진행하거나 가이드의 닫기/끄기·Escape, 설정의 끄기를 선택하면 같은 완료 표식을 기록하고 토글이 자동으로 꺼진다. 설정 화면을 보는 동안 안내는 잠시 숨기며 진행 상태는 유지한다. 설정 끄기 후 재실행에도 꺼짐을 유지하고, 켜진 상태에서 재실행하면 첫 단계부터 안내한다. 금융 데이터·계정·DB 설정에는 이 값을 저장하지 않는다.
