# 첫 사용 가이드와 연간 자산 축

2026-10-24 · android_dev.

연간 그래프의 자산/자산(부채포함) 축에서 1억원 이상은 `1.30억`, `1.31억`처럼 소수점 두 자리로 표시한다. 음수도 같은 규칙을 사용하며 지출입 그래프의 기존 축 표기는 유지한다. 금액 계산·자산 평가·장부 집계·그래프 범위는 변경하지 않는다.

첫 가이드는 자산 탭 → 자산 등록 + → 등록 후 장부 탭 → 거래 등록 + 순서다. 실제 메뉴 버튼을 하이라이트하고 옆에 안내를 표시한다. 모바일 하단 메뉴는 위쪽, 태블릿·PC 좌측 메뉴는 오른쪽에 안내한다. 등록 모달·수정/설정/확인 모달·동기화 중에는 입력을 가리지 않는다. 별도의 등록/저장 흐름을 만들지 않고 기존 버튼을 사용한다.

- 기존 사용자도 완료 표식이 없으면 한 번 표시한다.
- 기존 자산이 있으면 `이미 자산이 있어요 →`로 거래 안내를 진행할 수 있다.
- 자산 등록을 취소하면 자산 추가 안내를 유지한다. 등록 성공으로 자산 수가 증가한 뒤 장부 안내로 넘어간다.
- 마지막 거래 등록 창을 열면 가이드는 완료한다. 거래 저장을 강제하지 않는다.
- 닫기/안내 중 Escape도 완료로 기록한다. 등록 모달의 Escape를 가이드가 가로채지 않는다.
- 완료 표식은 기기 브라우저/WebView의 `memoney:usage-guide:v1:completed`다. 계정·장부 금융 데이터나 DB 동기화에 넣지 않는다. 같은 설치의 일반 업데이트/재실행에서는 유지되며 앱 데이터 삭제·재설치·다른 기기에서는 새 안내가 나올 수 있다.
- 기기 저장소를 쓸 수 없을 때는 현재 페이지 메모리에서 닫기 상태를 유지한다. 영구 저장이 불가능한 환경까지 재실행 비표시를 보장하지 않는다.

검증: production 웹 빌드, `node scripts/check-first-use-guide.mjs`의 4개 너비 × 2개 스타일 × 라이트/다크 16개 조합. 첫 자산 등록·취소·기존 사용자 건너뛰기·완료 후 재실행·직접 닫기 후 재실행·기존 기록 보존·소수점 두 자리 축을 확인했다. 테스트는 격리 브라우저의 합성 로컬 장부만 사용했고 금융 API 호출은 0건이다. Orca 로컬 화면에서 한글 안내와 실제 하이라이트 위치도 확인했다.

내부 테스트: 구현 커밋 `07ac207`으로 `3 (0.1.3)` AAB를 빌드하고 서명 검증 후 Play에 업로드했다. SHA-256은 `ed38b81e18458121507627374835922360b925aaf260ad27f9f849ad12b1b3b7`이다. 2026-10-24 23:51 KST에 Console에서 최신 `3 (0.1.3)` / 내부 테스터에게 제공됨을 확인했다. 기존 API·DB·로그인 설정을 유지하며 서버 재배포나 DB 변경을 하지 않았다. 공개 트랙으로 승급하지 않았다. 로컬 브라우저와 Vite 서버도 계속 열어둔다.

별도 발견: 기존 `src/auth/local-wallet.ts`의 `asset.create`가 신규 입력 기초금액을 `current?.amount || 0`으로 대체한다. 첫 자산 등록은 성공하지만 기초금액이 0이 될 수 있다. 이 가이드 변경에 포함해 저장 정책을 임의 수정하지 않았으며, `Docs/development-rules.md`의 저장 로직 사전 승인 규칙에 따라 사용자에게 별도 보완 여부를 요청했다.
