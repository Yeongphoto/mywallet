문서 자체만으로 개인정보처리방침을 공개했다고 보고하지 않는다. 접근 가능한 HTTPS 공개 URL과 앱 내 링크를 확인해야 한다.

## 데이터 보안 신고 대조표

| 데이터/기능 | 현재 근거 | 최종 신고 전 확인 |
| --- | --- | --- |
| 사용자 식별자 | `server/auth/store.ts`, Google issuer/subject | 계정 관리·앱 기능 목적, 필수/선택 구분 |
| 이메일 | 검증된 Google 연락 메타데이터·초대 | 로그인/공유 선택 시 처리, 제3자 제공 범위 |
| 금융 정보 | 사용자가 작성한 장부와 자산·예산 | 클라우드 선택 시 수집 항목 분류 |
| 사용자 작성 콘텐츠 | 거래 제목·자산 이름·메모·분류 | 개인식별정보가 입력될 수 있음 |
| 구매 내역 | 결제 검증 구현, 아직 비활성 | 실제 결제 활성화 버전 기준 갱신 |
| 기기/기타 ID·진단·광고 | 광고 SDK 없음 | Cloudflare/Google SDK와 운영 로그 실제 보존 확인 |
| 전송 보호 | HTTPS·HttpOnly Secure host-only 세션 | 모든 실제 origin과 네이티브 API 확인 |

금융기관 자동 연동·대출·투자 상품 매매 기능은 구현하지 않았다. 금융 기능 선언에서는 단순 가계부/재무 관리 기능에 맞는 현재 Console 선택지를 확인한다. 존재하지 않는 금융 서비스를 제공한다고 선택하지 않는다.

## 앱 접근 및 콘텐츠

- 로그인 없는 기기 장부는 심사자가 바로 사용할 수 있다.
- 개인·공유 장부 심사를 위해 개인 PD서 계정 비밀번호나 실제 가족 장부를 전달하지 않는다. 별도 심사용 계정/장부와 재현 절차를 준비한다.
- Google 로그인 계정 선택·초대 권한·기본 viewer/editor/owner 범위를 설명한다. 정식 Play 설치에서 검증 전 접근 가능하다고 신고하지 않는다.
- 현재 광고 없음. AdMob 등을 넣을 때 광고 포함 신고를 해당 버전에 맞춰 변경한다.
- 대상 연령·콘텐츠 등급은 가계부 기능과 실제 표시 콘텐츠 기준으로 질문에 답한다. 아동 대상으로 광고한다고 임의 선택하지 않는다.

1. 호스트 계정 삭제 시 장부 소유권 이전/공유 기록 처리 정책 확정.
2. 계정 삭제 요청 인앱·웹 경로 구현, 본인 확인과 다른 구성원 데이터 보호 검증.

4. 실제 제공 버전 기준 데이터 보안·광고·대상 연령·콘텐츠 등급·금융 기능 신고.
