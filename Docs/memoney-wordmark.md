# Memoney 로고

## 현재 구성 (2026-10-21)

기본·테마1 모두 같은 로고를 사용한다. 메인 화면은 `public/images/logo-cat-high.png`와 `public/images/mememo/memony-wordmark.png`의 조합이며, 로그인 화면은 기존 젤리 로고를 두 테마에서 동일하게 표시한다. 테마별 픽셀 SVG 전환과 별도 캐릭터의 중복 표시는 제거했다.

메인 화면에서는 `scripts/prepare-main-brand.mjs`로 만드는 화면 배율별 PNG를 사용한다. 캐릭터는 `main-cat-smooth-v2-{1,2,3}x.png`, 글자는 `main-name-smooth-v1-{1,2,3}x.png`다. 원본 비율과 투명 영역을 유지하며 단계적으로 축소한다. `logo-cat-high`와 이전 `logo-cat`의 해상도는 모두 1266×1242이며, 형태·광택이 서로 다르다.

사용하지 않는 픽셀 v1·v2, 둥근 SVG v1~v9, 이전 합본 PNG와 캐릭터 v1 축소본은 삭제했다. 사용자가 제공한 원본 이미지는 보존한다. 아래 내용은 과거 제작 이력이며 현재 배포 파일 목록이 아니다. 과거 파일은 Git 이력에서 확인할 수 있다.

## 과거 제작 이력

최신 적용은 v9(`memoney-wordmark-rounded-v9.svg`)이다. v8의 외곽선 없는 형태와 매우 얇은 내부 음영은 그대로 두고, 본체의 세이지색·민트색 명도를 낮추고 알파를 조금 높여 희미함을 줄였다. O의 민트 포인트와 나머지 글자의 낮은 채도, 중앙의 투명감은 유지한다. 아래는 버전별 이력이며 생성기 출력은 v9이다.

최신 적용은 v8(`memoney-wordmark-rounded-v8.svg`)이다. 사용자가 요청한 구분감은 테두리가 아니므로 `stroke`와 외부 접지 그림자를 없앴다. 가장자리 그라데이션의 짙은 색도 완화했다. 내부 음영만 침식 1.5·블러 1·알파 0.12로 매우 얇고 옅게 남긴다. O의 민트 계열과 나머지 글자의 낮은 채도는 유지한다. 아래는 이전 버전 이력이며 생성기 출력은 v8이다.

현재 적용은 v7(`memoney-wordmark-rounded-v7.svg`)이다. 사용자 요청으로 윤곽 획 확장은 88→29.333, AO 띠의 침식 반경은 28→9.333, 블러는 24→8로 각각 1/3로 줄였다. O의 민트 팔레트는 유지하고 나머지 글자 본체는 채도를 살짝 낮춘 세이지색으로 조정했다. 아래 버전별 설명은 변경 이력이며 생성기 출력은 v7이다.

현재 기본 로고는 `memoney-wordmark-rounded-v6.svg`다. 둥근 획 확장을 24에서 88 폰트 단위로 늘리고 글자 사이 공간도 확보했다. 기포는 글자당 최대 10개에서 2개로 줄였다. SVG의 알파 침식·블러·합성으로 윤곽과 내부 구멍 주변에 부드러운 안쪽 음영(AO 느낌)을 만들고, 아래에는 약한 접지 그림자를 더한다. 실제 3D 광원 계산이 아닌 정적인 2D 표현이며 본체의 반투명색과 곡선 반사광을 유지한다. 재생성 스크립트의 기본 출력은 v6다.

참고 젤리 이미지 반영 후 현재 기본 로고는 `memoney-wordmark-rounded-v5.svg`다. 넓은 직선 광택과 회색 본체를 빼고, 반투명 세이지·민트색 방사형 명암에 글자 윤곽 안으로 잘린 곡선 반사광과 작은 기포를 적용했다. O는 더 선명한 민트색으로 구분한다. 고정 SVG 표현이며 기포·기울기는 움직이지 않는다. 재생성 기본 출력은 v5다.

다크 모드 대응을 포함한 최종 반영은 `memoney-wordmark-rounded-v4.svg`다. 본체 투명도는 흰색 알파 마스크로 분리하고 글자색은 사용 위치의 `currentColor`를 상속한다. 외부 SVG의 gradient stop에 글자색을 의존하지 않아 라이트·다크 모두 본체와 윤곽이 같은 색 계열로 표시된다. 생성 스크립트의 현재 출력은 v4다.

현재 기본 로고는 반투명 젤리 v3(`memoney-wordmark-rounded-v3.svg`)다. v2의 글자 형태를 유지하고 본체의 중앙 알파를 잉크색 0.42·민트색 0.38까지 낮췄다. 가장자리는 0.72의 얇은 선으로 남기고 좌상단 하이라이트를 겹쳐 실제 배경이 비치는 SVG로 구성했다. 재생성 스크립트의 기본 출력도 v3이며 이전 버전은 보존한다.

기본 로고의 후속 젤리 버전은 `memoney-wordmark-rounded-v2.svg`다. Fredoka 700/너비 108을 사용하고, 둥근 획 확장과 글자별 미세한 높이·기울기 차이, 좌상단의 은은한 광택을 더했다. 중앙 O는 민트 그라데이션이며 애니메이션·블러는 없다. v1과 픽셀 원본은 보존한다. 재생성 스크립트는 현재 v2를 출력한다.

2026-10-15: 기본 테마에는 Fredoka 650/너비 100의 둥근 고딕 형태를 아웃라인한 `memoney-wordmark-rounded-v1.svg`를 사용한다. 테마1에서는 기존 픽셀 v2를 유지한다. 중앙 O의 민트색과 첫 M 아래의 세 점은 이어가되, 기본 로고의 점은 원형이다. 공통 `BrandWordmark`가 CSS의 `data-ui-theme`에 따라 표시할 벡터를 즉시 전환한다. 숨겨진 로고는 접근성 트리에서도 제외된다.

재생성: `scripts/build-rounded-wordmark.py`(fonttools 필요). 원본은 [Google Fonts Fredoka](https://github.com/google/fonts/tree/a60a77e14f28abd4ef243a1b5dfc48df0cec5205/ofl/fredoka)의 고정 버전이며 폰트 SHA-256은 `2ba02e68b152868aef9ba28e24b3648c7d457fe6f25c761f2c2c53fb61a73fc8`이다. 라이선스는 `public/licenses/Fredoka-OFL.txt`에 보관한다. SVG는 폰트 로딩이나 설치에 의존하지 않는 순수 경로이며, 기존 멧 표식·픽셀 원본·설치 아이콘·스플래시·로딩 이미지는 그대로 유지한다.

사용자가 제공한 1024×268 투명 MEMEMO PNG를 원본으로 보존했다. SVG 원본은 제공되지 않았으므로 `scripts/trace-memoney-wordmark.py`가 알파 128 이상인 픽셀의 행 구간을 합쳐 순수 SVG 경로로 변환한다. 원본 M·E·M·O·E와 첫 M 아래의 세 점을 재사용하고, MEMONEY 표기에 필요한 N·Y만 같은 픽셀 간격으로 새로 구성했다. 사용자 후속 요청으로 원본 민트색 `#68cfa2`를 가운데 O와 세 번째 점에 사용한다. Y는 다른 글자와 같은 진한 색이다.

원본: `public/images/mememo/mememo-wordmark-source.png`. 현재 산출물: `public/images/mememo/memoney-wordmark-v2.svg`. 이전 Y 포인트 v1은 캐시 호환을 위해 보존한다. SVG에는 이미지 내장·불투명 배경이 없으며, 글자 내부의 빈 부분은 투명하다. 단색 글자 부분은 `currentColor`로 밝기에 대응한다.

변환 수치: 재사용한 글자의 임계 마스크 IoU는 1.0이며 원본의 반투명 경계를 이진화하면서 생기는 평균 알파 절대 오차는 255 단계 중 2.6077이다. 원본 PNG와 모든 알파 값이 동일하다는 뜻은 아니다. 새 N·Y에는 원본과의 동일성 수치를 적용하지 않는다. 원본 해시와 산출 기준은 `memoney-wordmark-metrics.json`에 기록했다.

로그인·앱 상단·왼쪽 메뉴는 공통 `BrandWordmark`를 사용한다. 기존 멧 캐릭터, 설치 아이콘, PWA 매니페스트, 네이티브 스플래시, 캔버스 로딩 렌더러, 인증과 금융 저장은 변경하지 않는다. 배포는 Android 격리 테스트 사이트에만 반영하고 APK는 만들지 않았다.
