# MEMEMO 브랜드 색상 규격

2026-10-26 지정. MEMEMO Windows 앱과 메머니(Memoney)가 공유하는 메메모 계열의 색상 기준이다. 현재 메머니의 민트·초록 UI를 출발점으로 삼는다. 이 문서 작성으로 Windows 앱이나 메머니의 실행 코드를 변경하지는 않는다.

관련 문서: [Windows 젤리 UI 적용 지침](mememo-windows-jelly-ui-guide.md).

## 1. 대표색

| 토큰 | 색상 | 역할 |
| --- | --- | --- |
| `brand.mint` | `#ABE8C3` | MEMEMO 대표색. 브랜드 바, 대표 배경, 브랜드 표현 |
| `brand.green` | `#36785B` | 강조색. 주요 동작, 링크, 밝은 배경의 브랜드 표현 |
| `brand.ink` | `#233E31` | 민트 위 로고·제목·아이콘에 사용하는 짙은 초록 |

**대표색은 민트, 동작 강조색은 딥그린으로 구분한다.** 대표 민트를 흰 글씨 버튼의 배경으로 그대로 사용하지 않는다. 민트에는 `brand.ink`, 딥그린에는 흰색을 조합한다.

브랜드 원색 3개는 라이트·다크에서 같은 값을 유지한다. 다크 화면에서 원색을 바꾸는 대신 원색이 놓이는 표면·경계·글자 역할을 바꾼다. 새 로고나 아이콘을 이 문서를 근거로 다시 그리거나 기존 이미지 픽셀을 임의 보정하지 않는다. 원본 이미지와 UI 토큰은 별도로 관리한다.

## 2. 화면 역할색

아래 값은 현재 메머니의 [기본 계열 색상](../src/memoney-family.css)을 토대로 정리한 MEMEMO 적용 기준이다. 브랜드 원색과 달리 화면 역할색은 테마에 따라 바뀐다.

| 역할 토큰 | 라이트 | 다크 |
| --- | --- | --- |
| `surface.app` | `#EEF7F0` | `#192923` |
| `surface.sidebar` | `#F5FBF6` | `#20372D` |
| `surface.card` | `#FCFEF9` | `#243B31` |
| `surface.input` | `#FFFFFF` | `#1C3027` |
| `surface.soft` | `#E6F4E9` | `#304B3D` |
| `surface.toolbar` | `#E1F5E8` | `#294638` |
| `text.primary` | `#293E35` | `#EDF7EF` |
| `text.secondary` | `#596E63` | `#BACFC0` |
| `border.card` | `#557563` | `#91B6A1` |
| `border.input` | `#6C8577` | `#91B6A1` |
| `shadow.ink` | `#557563` | `#101B14` |

현재 메머니에는 다크의 `--family-mint: #8EC7AA`, `--primary: #AFD8B3`처럼 역할에 따라 조정한 기존 값도 있다. 이것은 기존 UI 표면색이며, 새로 지정한 불변 `brand.mint`와 같은 토큰으로 취급하지 않는다. Windows 쪽에서 `Primary` 하나를 로고·버튼·배경·본문에 함께 쓰지 않는다.

## 3. 젤리 표면색

| 토큰 | 라이트 | 다크 |
| --- | --- | --- |
| `jelly.top` | `#C6F5DB` | `#39785D` |
| `jelly.bottom` | `#8ED8B2` | `#24513E` |
| `jelly.edge` | `#65AE89` | `#65B58E` |

젤리는 대표 민트와 어울리는 UI 재질이다. 그라데이션 상·하단색을 브랜드 원색으로 다시 정의하지 않는다. 선택·누름에 따른 반응은 이동·압축·복원으로 표현하고, hover 때마다 대표색을 어둡게 바꾸는 방식은 기본 효과로 추가하지 않는다.

기본 글자색은 `text.primary`를 사용한다. 광택을 합성한 최종 표면에서 대비를 확인한다. 위·아래 기본색만 검사한 결과가 여러 겹의 흰 광택까지 검증한 결과는 아니다.

## 4. 보조색과 상태색

보조색은 메모 분류·장식·태그에 제한해서 사용한다. 주요 동작과 현재 선택은 민트·초록 계열로 유지한다.

| 보조색 | 라이트 | 다크의 대응 표면색 |
| --- | --- | --- |
| 블루 | `#BAD9E5` | `#B0C9D7` |
| 피치 | `#F5C5A1` | `#E8BB9B` |
| 옐로우 | `#F4DF9A` | `#E5D093` |

상태색은 브랜드 강조색과 별도 이름으로 관리한다. Windows 앱에서 상태가 필요한 경우 다음 계열을 사용한다. 이 표는 새 적용 규격이며 Windows 앱의 기존 상태색을 조사·변경한 결과는 아니다.

| 의미 | 라이트 | 다크 |
| --- | --- | --- |
| 정보 `status.info` | `#3B82F6` | `#60A5FA` |
| 성공 `status.success` | `#10B981` | `#34D399` |
| 주의 `status.warning` | `#F59E0B` | `#FBBF24` |
| 오류·삭제 `status.danger` | `#EF4444` | `#F87171` |

상태색만으로 의미를 전달하지 않고 아이콘·문구를 함께 표시한다. 상태색을 그대로 채운 버튼의 흰 글씨 대비는 별도 검증한다. 특히 삭제를 일반 민트 동작으로 바꾸지 않는다. 일반 닫기 X는 중립 글자색, 실제 삭제는 danger로 역할을 구분한다.

## 5. 기본 조합과 대비

상대 휘도 공식으로 계산한 불투명 단색 조합이다. 소수점 둘째 자리 반올림 값이며 실제 이미지·그라데이션·투명 레이어의 대비를 대신하지 않는다.

| 글자 / 배경 | 대비 | 용도 |
| --- | --- | --- |
| `#233E31` / `#ABE8C3` | 8.35:1 | 대표 민트 위 제목·아이콘 |
| `#FFFFFF` / `#36785B` | 5.26:1 | 딥그린 주요 버튼 |
| `#293E35` / `#FCFEF9` | 11.27:1 | 라이트 카드 본문 |
| `#596E63` / `#FCFEF9` | 5.39:1 | 라이트 보조 문구 |
| `#EDF7EF` / `#243B31` | 10.98:1 | 다크 카드 본문 |
| `#BACFC0` / `#243B31` | 7.32:1 | 다크 보조 문구 |
| `#FFFFFF` / `#ABE8C3` | 1.39:1 | 일반 글자 조합으로 사용 금지 |

일반 글자 4.5:1, 큰 글자 3:1, 의미 있는 경계·아이콘 3:1을 목표로 한다. disabled는 단순히 전체 컨트롤 opacity를 낮춰 읽을 수 없게 만들지 말고 비활성 표면·문구를 명시한다. 포커스 표시는 선택 표면·광택과 별개로 제공한다.

## 6. 구현 계약

웹 기반 Windows UI는 아래처럼 이름이 겹치지 않는 브랜드 토큰부터 만든다. WPF/WinUI 등은 같은 이름과 값을 리소스 키로 옮긴다. 실제 사용 위치에는 역할 토큰을 연결한다.

```css
.mememo-ui {
  --mememo-brand-mint: #abe8c3;
  --mememo-brand-green: #36785b;
  --mememo-brand-ink: #233e31;
  --mememo-jelly-top: #c6f5db;
  --mememo-jelly-bottom: #8ed8b2;
  --mememo-jelly-edge: #65ae89;
}
.mememo-ui[data-theme="dark"] {
  --mememo-jelly-top: #39785d;
  --mememo-jelly-bottom: #24513e;
  --mememo-jelly-edge: #65b58e;
}
```

대표색은 한 곳에서만 선언하고 개별 화면에 HEX 값을 복제하지 않는다. 색상 변경 시 로고가 놓인 표면, 주요 버튼, 선택 토글, 입력 필드, 상태 메시지를 함께 확인한다. Windows 고대비 모드에서는 시스템 색상과 포커스 식별을 우선하며 광택·그림자 없이도 현재 선택을 알 수 있어야 한다.
