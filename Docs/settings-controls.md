# 설정 메뉴와 장부 초기화 표시

2026-10-26: 설정 상단의 환경·카테고리·자산관리·정기기록·데이터 선택에 기존 `JellyToggle`을 재사용한다. `annual-chart-toggle.css`의 공통 젤리 표면·이동·광택·동작 줄이기 규칙에 설정 메뉴를 포함한다. 라이트/다크 및 테마1의 기존 색상과 모서리 규칙을 유지한다.

기존 장부 초기화 버튼은 `LedgerRecovery`의 복구 조회가 완료된 후에만 생성돼 느린 네트워크에서 뒤늦게 나타났다. 소유자에게는 안내와 버튼을 처음부터 표시하고, 최신 복구 상태 조회가 성공할 때까지 비활성화한다. 안내와 버튼 위치는 조회 완료 전후 동일하다. 조회 시간 자체를 단축하거나 이전 상태를 캐시해 초기화를 허용하는 변경은 아니다.

조회 실패 시 비활성 상태와 오류 안내를 유지한다. 보관/만료 상태와 게스트에게 초기화 권한을 추가하지 않으며, 기능 미설정 상태도 기존 규칙을 유지한다. 확인 문구 입력·세대 확인·초기화/보관/복구 저장 경로는 변경하지 않는다. 초기화 실행 오류 후 기존 재시도 동작도 유지한다.
