# [기획서] 일일 용돈 다이어트 & 돼지저금통 (Daily Budget Diet & Piggy Bank)

> **문서 상태:** 프로토타입 기획 완료 (Design Complete)  
> **관련 모듈:** 설정(Settings), 장부(Ledger), 소비 캘린더(Calendar)  
> **핵심 가치:** 0원 무지출의 한계를 보완하여, 일일 정해진 예산 안에서 절약하고 남은 잔돈을 저금통에 저금하는 일상적 성취감 제공

---

## 1. 기획 배경 및 의도

1. **무지출 챌린지의 한계 극복:**
   - 지출 0원을 지향하는 무지출 챌린지는 효과적이지만, 커피 한 잔이나 생수 한 병 등 필수적인 소액 소비가 발생하는 날에는 즉시 '실패' 처리가 되어 사용자의 참여 동기가 쉽게 꺾임.
2. **"남긴 만큼 돈이 모이는" 긍정적 게이미피케이션:**
   - "돈을 아예 쓰지 말라"는 압박 대신, "오늘 정해진 하루 용돈(예: 20,000원) 안에서 아껴 쓰고, 남은 돈은 매일 밤 내 가상 저금통에 저금하자!"라는 따뜻하고 성취감 있는 규칙 적용.
3. **MyWallet 두들 감성 마스코트(돼지저금통 🐷🪙) 결합:**
   - 가계부의 상징인 돼지저금통을 능동적인 다마고치 캐릭터처럼 활용하여, 하루 소비 상태에 따라 돼지의 표정과 멘트가 반응하도록 설계.

---

## 2. 핵심 게임 규칙 & 판정 로직

### 2.1 일일 목표 용돈 (Daily Budget Allowance)
- 기본값: **20,000원** (설정에서 1만, 2만, 3만, 5만 또는 직접 입력 가능).
- 매일 자정 기준으로 새로운 하루 용돈 한도가 리셋됨.

### 2.2 실시간 잔여 용돈 계산
$$\text{오늘 남은 용돈} = \text{일일 목표 용돈} - \text{오늘 실제 총 지출}$$

### 2.3 하루 4단계 결과 판정
| 상태 | 판정 조건 | 돼지 상태 & 시각 피드백 | 저금통 적립 결과 |
| :--- | :--- | :--- | :--- |
| 🌟 **초과 세이브 (슈퍼 세이버)** | 오늘 지출 0원 (무지출 달성) | 선글라스 낀 슈퍼 돼지 😎 | 하루 용돈 전액 저금! 🪙 |
| 🟢 **알뜰 방어 성공** | 목표 이내 지출 (남은 돈 > 0) | 배부르고 활짝 웃는 돼지 🐷 | **남은 잔여 금액 전액 저금!** 🪙 |
| 🟡 **본전 방어** | 정확히 일치 (남은 돈 = 0원) | 안도하며 땀 닦는 돼지 😌 | 0원 저금 (방어 성공 인정) |
| 🔴 **다이어트 초과** | 목표 초과 지출 (남은 돈 < 0) | 땀 삐질 흘리며 반성하는 돼지 💦 | 저금 실패 (내일 다시 도전!) |

### 2.4 월간 누적 저금통 (Monthly Piggy Vault)
- 해당 월 동안 '알뜰 방어 성공' 및 '무지출'을 통해 모인 잔여 금액을 전수 합산:
  - 예: *"이번 달 내 저금통에 모인 돈: **🪙 138,000원** (총 22일 방어 성공)"*
  - *"치킨 6.2마리 🍗 또는 커피 27잔 ☕ 어치를 지켜냈어요!"*

## 3. 화면별 UI/UX 상세 설계

### 3.1 [설정 탭] 환경 설정 & 용돈 금액 관리
- **토글 옵션**:
  ```text
  일일 용돈 다이어트        [ 🪙 켜짐 / 꺼짐 ]
  하루 정해진 예산에서 남은 돈을 매일 밤 가상 저금통에 저금합니다.
  ```
- **목표 금액 설정 (활성화 시 펼쳐짐)**:
  - `하루 목표 용돈`: `[ 20,000 ]` 원
  - 퀵 칩: `[ 10,000원 ]` `[ 20,000원 (기본) ]` `[ 30,000원 ]` `[ 50,000원 ]`

### 3.2 [장부 탭] 오늘 카드 / 상단 미니 게이지 위젯
- 장부 탭 상단 또는 오늘 카드 영역에 실시간 용돈 프로그레스 바 제공:
  ```text
  ┌────────────────────────────────────────────────────────┐
  │ 🐖 오늘의 용돈 다이어트           [ 11,000원 남음 🪙 ] │
  │ 20,000원 중 9,000원 사용                               │
  │ [████████████░░░░░░░░░░] 55% 세이브 중                 │
  │ 💬 "저녁만 지키면 오늘 11,000원이 저금통으로 쏙 들어가요!"│
  └────────────────────────────────────────────────────────┘
  ```
- 목표 초과 시:
  ```text
  │ 🐖 오늘의 용돈 다이어트             [ 5,000원 초과 💦 ] │
  │ 20,000원 중 25,000원 사용                              │
  │ [██████████████████████] (내일 다시 도전해봐요!)       │
  ```

### 3.3 [달력 탭] 일일 달력 셀 & 월간 저금통 리포트
- **달력 셀**: 알뜰 방어 성공 날짜 셀에 작은 저금통 동전 배지(`🪙 +11,000`) 렌더링.
- **달력 상단 요약 배너**:
  - `이번 달 누적 저금: 🪙 142,000원 (달성 18일 / 실패 3일)`
  - 클릭 시 저금통 개봉 팝업 모달 제공.

## 4. 데이터 무결성 보존 원칙 (`AGENTS.md`)

1. **금융 원장 완전 무결성:**
   - `transactions`, `assets` 등 D1 SQLite 테이블 스키마를 전혀 변경하지 않음.
   - 지출 합계는 기존 집계 엔진에서 읽어오는 **100% 파생 상태(Derived State)**로 처리.
2. **설정값의 안전한 격리 보존:**
   - `localStorage['mywallet:dailyBudgetDietEnabled']` (활성화 여부)
   - `localStorage['mywallet:dailyBudgetDietAmount']` (목표 금액)
   - 장부 sync 로직 및 revision 시스템과 완전히 분리되어 데이터 충돌 위험 0%.
