# 등록·수정 입력 화면 통일

2026-10-23 사용자 요청: 장부 수정 모달을 등록 모달의 공통 구조와 스타일로 맞춘다. 필드 순서는 날짜/시간 → 금액 → 카테고리/계좌 → 내용이다. 수정은 선택한 항목만 처리하고 다른 입력창으로 자동 이동하지 않는다. Enter는 내용 입력을 마치며 저장은 저장 버튼으로만 확정한다.

- 수정 화면도 기존 `entry-modal`, `entry-form`, `form-grid`, `entry-actions`를 재사용한다. 별도 규격이나 `!important`를 추가하지 않았다.
- 수정 전용 모바일 헤더 여백은 제거해 등록 화면의 규칙을 따른다. 할부 요약은 기존 내용을 유지하고 2열 전체를 차지한다.
- 카테고리/출금/입금 계좌 선택 후 다음 팝업이나 내용 입력으로 이동하지 않는다. 날짜/시간/금액도 현재 선택창만 닫는다. 등록의 순차 입력은 유지한다.
- 기존 키패드 초기화·젤리 반응·금액 수직 정렬을 보존한다. 저장/정기기록/인증/DB 로직은 수정하지 않는다.

검증: `npm run build`, 인증 49건, 최초 이전 17건 통과. `scripts/check-entry-edit-layout.mjs`는 격리 로컬 데이터와 API 차단 상태에서 411×900, 411×560, 768×700, 1080×900 · 기본/테마1 · 라이트/다크 · 지출/수입/이체의 48개 조합을 확인한다. 등록 대비 필드 순서/높이/간격/버튼 크기, 항목별 완료 후 자동 이동 없음, 취소 시 원본 유지, Enter 비저장 및 명시적 저장을 검사한다. 금융 네트워크 호출은 0건이다. 산출물은 저장소 밖 `%LOCALAPPDATA%/Memoney/web-ui-checks`에 보관한다.

## 테스트앱 배포 범위

설치 앱의 URL은 `https://memoney-android-test.pages.dev/signin`이다. 배포 전 canonical은 `b93451b3-5548-48c9-a26d-23ecca833f99`(메타데이터 `8e5b1c9`)였다. 실제 응답 HTML 및 진입 JS/CSS와 일치하는 `android/build/picker-release-MdKtob`의 동결된 소스·runtime에 이번 UI diff만 적용했다. 원격 배포는 전체 최신 브랜치 배포가 아니다.

배포 준비 위치는 `%LOCALAPPDATA%/Memoney/entry-edit-release-0fc1ded6`이다. 기존 runtime의 `functions` 7개·`server` 15개 파일과 `wrangler.json`은 바이트 단위로 유지한다. 공통 DB ID와 모든 인증 설정은 그대로이며, 최초 이전 플래그를 켜지 않는다. 미배포 최초 이전/정기발생 서버 변경을 포함하지 않는다. 동결된 배포용 소스의 빌드와 같은 48개 UI 검사도 통과했다. APK·DB 변경/삭제·원격 Git 푸시는 필요하지 않다.
