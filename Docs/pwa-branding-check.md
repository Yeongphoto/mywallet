# PWA 로고 교체 점검

Android 앱 시작 화면은 설치된 WebAPK의 아이콘으로 운영체제가 그린다. 이어지는 앱 로딩 화면은 `public/logo.png`와 CSS로 그린다. 두 화면은 렌더러가 달라 모든 기기에서 픽셀 단위로 일치한다고 보장할 수 없다. 특정 기기에서 크기와 위치를 맞출 때는 그 기기의 실제 화면 녹화를 프레임별로 비교한다.

## 교체할 때

1. `public/logo.png`를 로딩 화면의 원본으로 삼고, PWA 192·512 아이콘과 maskable 아이콘을 같은 그림에서 생성한다. maskable 버전은 Android 안전 영역 때문에 더 작을 수 있다. 아이콘에 별도의 사각 테두리·배경 무늬를 추가하지 않는다.
2. `npm run check:pwa`와 `npm run build`를 실행한다. 검사는 원본 대비 로고의 실제 흰색 도형 범위·중심·면적, 아이콘 크기·배경, 매니페스트 연결을 확인한다.
3. 매니페스트 **주소** `/manifest.webmanifest`는 바꾸지 않는다. 아이콘 URL만 버전 갱신하고 서비스 워커 캐시 이름도 갱신한다.
4. Android에 설치된 앱을 화면 녹화해 운영체제 스플래시와 앱 로딩 화면을 따로 확인한다. PC 브라우저 미리보기나 빌드 성공만으로 Android 첫 화면을 검증했다고 처리하지 않는다.

2026-10-02 실제 녹화에서는 운영체제 스플래시의 고양이 흰색 도형이 약 91×76px, 앱 로딩 화면은 약 106×89px이었다. 당시 CSS의 57px 로고를 49px로 조정하면 같은 화면 배율에서 약 91×77px이 된다. 이 측정값은 해당 기기에 한정된다. 원본 이미지의 캔버스 비율이 같다는 이유로 실제 표시 크기도 같다고 판단하지 않는다.

## 설치된 앱에서 옛 아이콘이 보일 때

먼저 서버가 새 매니페스트와 아이콘을 제공하는지 확인한다. Chrome의 `about://webapks`에서 해당 앱의 갱신 상태를 확인하고, 필요한 경우 갱신을 요청한다. Chrome은 설치된 PWA의 매니페스트를 즉시 매번 갱신하지 않으며 WebAPK 갱신에도 조건이 있다. 앱 삭제·재설치는 저장된 데이터에 영향을 줄 수 있으므로 자동으로 수행하지 않는다.
