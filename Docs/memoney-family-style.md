# Memoney 패밀리 스타일

현재 설정에는 **기본 / 테마1** 비교 선택이 다시 추가됐다. 기본은 이 문서의 패밀리 스타일을 보존하며, 테마1은 직각 모서리와 얇은 테두리의 비교안이다. 저장·전환과 검증은 [테마 비교](theme-comparison.md)를 따른다.

2026-10-15 사용자 요청으로 기본·두들·메메모 선택 UI를 제거했다. 이후 고전 윈도우 방향을 철회하고, 새 참고 이미지의 파스텔 제목줄·짙은 외곽선·둥근 모서리·단단한 그림자를 사용하는 단일 패밀리 스타일로 표시한다. 라이트·다크·시스템 밝기 선택은 유지한다.

- 크림색 바탕, 민트·하늘색 제목줄, 갈색 외곽선과 1~2px 오프셋 그림자를 사용한다. 회색 입체 베벨과 고정폭 글꼴은 제거했다. 앱 상단은 멧·MEMONEY 제목줄과 월 이동·설정 도구 모음의 두 행으로 구성하되, 바깥 창 테두리·모서리·그림자 없이 좌우를 채운다.
- 작은 반경의 둥근 버튼과 창 모서리를 사용한다. 금액과 거래 내역의 글꼴 및 수입·지출·자산·이체 의미 색상은 유지한다.
- 팝업은 하늘색 제목줄·복숭아색 닫기 버튼으로 구성한다. 선택 전후 하단 메뉴의 테두리 공간과 위치를 고정해 크기가 흔들리지 않게 한다.
- 버튼과 메뉴의 색·그림자 전환 애니메이션을 사용하지 않는다. 선택 해제한 메뉴의 hover 배경도 제거해 이전 선택의 잔상이 남지 않게 한다.
- 멧은 기존 `mememo-met-green.png`와 `mememo-met-mint.png` 원본을 재사용한다. 설치 아이콘·스플래시·캔버스 로딩 이미지는 수정하지 않는다.
- `src/memoney-family.css`가 공통 외형을 담당한다. 기존 테마 정의와 저장 값은 향후 확장과 호환성을 위해 보존하며, 초기 HTML·장부·인증 화면 모두 `data-style-theme="default"`로 표시한다. 표시 통일을 위해 기존 장부 설정을 마이그레이션하거나 금융 데이터를 저장하지 않는다.
- 배포 대상은 격리된 Android 테스트 사이트다. 기존 운영 웹앱에는 배포하지 않으며 APK는 사용자가 요청할 때 만든다.

## 폴드·태블릿 배치

`src/family-adaptive.css`는 기기 이름이나 물리 해상도 대신 앱에 실제로 주어진 CSS 폭을 사용한다. 600px 미만은 하단 메뉴, 600~839px은 88px 왼쪽 메뉴, 840~1199px은 180px 메뉴, 1200px 이상은 220px 메뉴다. 화면 크기 변경만으로 현재 장부·화면·인증 상태를 초기화하지 않는다.

4:3의 800×600·1024×768·1280×960, 세로 768×1024, 599/600·839/840·992/993 경계에서 차트·장부·자산·설정을 라이트·다크로 확인한다. 브라우저 배치 검사는 88개 조합이다. 이는 실제 폴드의 힌지·접힘 이벤트·키보드·삼성 멀티윈도우 검증을 대체하지 않는다.

사용자의 동시 표시 요청으로 `Memoney_Unfolded_4_3` AVD를 별도로 만들었다. Medium_Phone은 오르카의 세로 기기로 유지하고, 새 기기는 별도 scrcpy 창에서 2048×1536·320dpi로 표시한다. 새 기기는 자체 로컬 장부로 시작했으며 기존 기기의 계정·세션·장부 데이터를 복사하지 않았다. 재실행은 `npm run android:unfolded`다.
